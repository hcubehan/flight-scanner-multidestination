# Browser search without partner API access

Use the browser automation surface available in the current session, reading its initialization and interaction documentation first. Open [Skyscanner Singapore](https://www.skyscanner.com.sg/) and inspect visible state. Do not use hidden web APIs, scripted scraping of private endpoints or CAPTCHA workarounds.

For each requested destination, select return travel, SIN origin, the destination city/all airports, the exact departure and return dates, economy and the requested passengers. Select SGD. Use autocomplete and visible options to resolve names, including the country. Verify selected fields before searching. Select direct/nonstop-only and sort cheapest; check that both directions have no stops in the displayed itinerary, since a "direct" label alone may not prove there is no intermediate stop.

Wait for visible search results to finish loading using supported state observations. Record up to five distinct round trips, not five booking agents for one flight pair. Expand result details or seller options only as necessary to confirm flight numbers, airport-local dates/times, fare scope, baggage and seller links. Use a read-only DOM/link observation supported by the tool to copy observed URLs; do not invent booking URLs. If only a results-page URL is available, label it as the source search link instead of a seller booking link. On pages quoting an average per traveler, calculate and label the party total only after verifying passenger count and price basis.

If Skyscanner shows a CAPTCHA, stop automated interactions with it and explain that a user must complete the verification or provide approved API access. Leave the browser available for handoff when supported. Never turn a challenge, login requirement, unfinished loading or network error into "no flights found". After user completion, inspect the current state before resuming. Use a bounded retry for ordinary transient loading failures; do not cycle hosts, proxies or guessed URL variations to evade a block.

Return genuine observed quotes with source links and Asia/Singapore retrieval time. When access is blocked, report the blocker and the cities still unsearched. Do not use generic web-search snippets as replacement quotes. Routine flight search is permitted by the user's quote request; purchase, account creation and notification subscriptions need their own authorization.
